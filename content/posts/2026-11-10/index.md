DGrid AI is partnering with DI (Decentralized Intelligence) to support its Agent Network. DGrid will provide a unified, low-cost AI API for model access and verifiable inference, giving DI a common infrastructure layer for the model calls behind its agent workflows.

## From Market Signals to Research

Built around a crypto-native model, DI connects market data, event research, quantitative products, and interoperable agents. Its Data Dashboard combines real-time market data with sentiment and news from 8,000+ X accounts and 500+ media sources. The Event Engine examines market events from different analytical perspectives and preserves the evidence and discussion behind each analysis. Users can authorize an on-chain proof for a specific version of that record.

DI’s AI Quant Intelligence gives users tools to build and publish their own quantitative strategies. Its Agent Network is designed to let personal agents exchange findings, draw on one another’s capabilities, and collaborate on financial tasks.[ DI’s approach to event research](https://medium.com/didotxyz/anatomy-of-an-event-intelligence-workflow-4722f6dbfbaa)

## One API for Different Agent Tasks

When a protocol publishes a governance proposal, one agent could summarize the proposed changes while another examines the market reaction. A third could combine their findings into a research brief that links back to the evidence.

Pulling facts from a proposal and comparing possible market effects place different demands on a model. The DGrid AI Gateway gives DI a single interface for calling models from different providers, so DI can match each task to a model based on its cost and performance requirements.[ DGrid model access](https://blog.dgrid.ai/posts/2026-07-23/)

## Looking Ahead

As DI’s Agent Network develops, a team could make a specialized tool, such as a governance tracker, available to other agents. That gives builders a way to reach users beyond their own applications. We see crypto research as a starting point for bringing more of these tools to the Web3 market.
